# Historical archive notice — 2025

The documents in this directory are retained as historical evidence of the project's 2025 architecture, terminology, assumptions, and operating model.

They are **not canonical statements of current SOAiaCore runtime state** and should not be read as present-tense production claims unless a current validation receipt explicitly confirms the same condition.

## Interpretation rule

When a statement in this directory conflicts with a newer architecture decision, validation receipt, runtime observation, or canonical project document, the newer evidence governs the current technical state. The historical document remains unchanged as provenance.

## Evidence classification

Material in this directory is classified as:

**HISTORICAL / NON-CANONICAL**

Retention of these files does not certify that services, infrastructure, autoswitch behavior, observability, integrations, or deployment states described in them remain active.

## Why the source text is preserved

Historical documents are not silently rewritten to resemble the present. Preserving the original record keeps changes in architecture and interpretation auditable over time.
